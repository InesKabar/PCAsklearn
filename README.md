# PCA Analysis with Scikit-Learn

A Python project demonstrating Principal Component Analysis (PCA) for dimensionality reduction using the Breast Cancer dataset provided by Scikit-Learn.

## Project Overview

The project uses the Breast Cancer dataset included in Scikit-Learn and applies data standardization followed by Principal Component Analysis.

PCA is used to reduce the dimensionality of the dataset from its original features to two principal components, making the data easier to visualize and analyze.

## Technologies

- Python
- NumPy
- Pandas
- Scikit-Learn
- Matplotlib

## Dataset

The project uses the Breast Cancer dataset provided directly by Scikit-Learn through `sklearn.datasets`.

The dataset does not need to be downloaded separately.

## How It Works

1. Load the Breast Cancer dataset from Scikit-Learn.
2. Convert the dataset into a Pandas DataFrame.
3. Standardize the features using `StandardScaler`.
4. Apply PCA using two principal components.
5. Transform the standardized data into the new two-dimensional representation.
6. Visualize the resulting data using a scatter plot.
